# To-Do List CLI App using Python

## Description
A simple command-line application developed using Python to manage daily tasks. Users can add, view, and remove tasks through an interactive menu.

## Features
- Add new tasks
- View all tasks
- Remove tasks by task number
- Handle invalid inputs
- Interactive menu-driven interface

## Technologies Used
- Python 3
- VS Code

## How to Run
1. Install Python 3.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Run the following command:

```bash
python todo_list.py
```
